# Offline stockout-aware forecasting experiment

This directory reproduces the experimental `stockout_lgbm_ratio_v1` benchmark.
It is not a production training service and it does not read ReorderLens customer
records. The application continues to save `seasonal_baseline_v1` forecasts.

## Data and license

The benchmark uses FreshRetailNet-50K v1.0 from Dingdong-Inc:

- Dataset card: https://huggingface.co/datasets/Dingdong-Inc/FreshRetailNet-50K
- Technical report: https://arxiv.org/abs/2505.16319
- Official baseline code: https://github.com/Dingdong-Inc/frn-50k-baseline
- Dataset license: CC BY 4.0; official baseline code: Apache-2.0

The downloaded Parquet files stay under ignored `artifacts/`. The downloader
verifies the exact SHA-256 values used for the recorded evaluation.

## Reproduce

Use Python 3.14.6 in an isolated environment. These commands do not change the
Next.js dependency graph:

```powershell
python -m venv artifacts/ml-evaluation/venv
artifacts/ml-evaluation/venv/Scripts/python -m pip install -r ml/forecasting/requirements.txt
artifacts/ml-evaluation/venv/Scripts/python ml/forecasting/download_dataset.py
artifacts/ml-evaluation/venv/Scripts/python ml/forecasting/benchmark.py
artifacts/ml-evaluation/venv/Scripts/python ml/forecasting/export_model.py
```

On macOS/Linux, use `artifacts/ml-evaluation/venv/bin/python`. The benchmark
writes the native model and full JSON report to `artifacts/ml-evaluation/run/`.
The compact checked-in artifact was generated by `export_model.py`; its parity
vectors are exercised by the TypeScript unit tests.

## Scope

The model uses only deployable features from the preceding 28 days: recorded
sales, known stockout/available status, promotion flags, weekday, lags and rolling
statistics. It predicts a scale-normalized seven-day ratio and applies one
validation-defined calibration factor. Future availability, future promotions,
store/product IDs, category, weather and target-period facts are excluded.

Primary metrics score only target days with zero recorded stockout hours. History
may contain stockouts. This evaluates forecasting after censored histories; it
does not establish latent demand or reconstruct lost sales.

See [the evaluation report](../../docs/FORECAST_MODEL_EVALUATION.md) for results,
limitations and the decision not to activate this artifact in saved forecasts.
